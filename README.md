# josou-dev
Toi qui est passionné du réseau, trouve ici un chat qui va te permettre de connaitre les base du réseau comme le DHCP, ce que s'est en réalité et ce que ça fait. Ainsi que le DNS, NAT, VLAN, un switch, un routeur. De même que des information sur les certificat lié au monde du réseau comme notamment le CCNA, le MTCNA, ainsi que d'autre certificat.
